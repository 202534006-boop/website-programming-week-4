# AI Disclosure

## Penggunaan AI

Dalam pengerjaan Tugas 4, saya menggunakan bantuan AI untuk memahami dan mengecek penerapan CSS Flexbox serta layout responsif.

### Prompt yang digunakan

* Meminta penjelasan sederhana tentang penggunaan Flexbox.
* Meminta bantuan mengecek struktur CSS agar layout dapat menyesuaikan ukuran layar.
* Meminta bantuan memahami penggunaan `flex-wrap`, `flex-basis`, `gap`, dan `min-width: 0`.
* Meminta bantuan mengecek kemungkinan terjadinya horizontal overflow.

### Saran AI yang digunakan

Beberapa saran yang digunakan dalam pengerjaan adalah:

* Menggunakan Flexbox untuk navigasi.
* Menggunakan `flex-wrap` agar elemen dapat berpindah ke baris berikutnya.
* Menggunakan `flex` dan `flex-basis` untuk membuat ukuran elemen fleksibel.
* Menggunakan `min-width: 0` untuk membantu mencegah overflow pada item Flexbox.
* Menggunakan `position: relative` pada card dan `position: absolute` pada badge.

### Pengujian

Setelah menerapkan perubahan, saya melakukan pengujian secara mandiri dengan:

* Mengecek tampilan pada layar lebar.
* Mengecek tampilan pada viewport sekitar 320px.
* Mengecek Flexbox melalui Chrome DevTools.
* Mengecek Console untuk error.
* Mengecek halaman menggunakan Nu HTML Checker.
* Mengecek fokus menggunakan keyboard.

### Perubahan mandiri

Saya menyesuaikan kode HTML dan CSS dengan kebutuhan tugas, termasuk struktur halaman, navigasi, card, badge, gambar, form, dan layout responsif.
