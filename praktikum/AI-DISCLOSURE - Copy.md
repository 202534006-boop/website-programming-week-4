# AI Disclosure

ChatGPT

## Prompt utama

Saya menggunakan ChatGPT untuk membantu memahami dan menerapkan CSS pada halaman proyek Minggu 2, termasuk custom properties, selector, box model, spacing, typography, navigation, card, form, hover, active, dan focus-visible.

## Saran dari AI yang digunakan

Saya menggunakan beberapa saran untuk menghubungkan file `style.css` dengan `index.html`, membuat custom properties untuk warna, spacing, dan radius, serta menata navigation, gambar, card, form, dan focus indicator.

Saya juga menggunakan saran untuk memahami cascade dan specificity melalui pemeriksaan aturan CSS pada DevTools.

## Pengujian

Saya menguji website menggunakan Chrome, Live Server, Nu HTML Checker, DevTools, keyboard focus, hover, contrast, Network, Console, dan Zoom 200%.
